Changelog

Historial de versiones del CLI, instalador curl, web y API. También en GitHub.

2.0.0

30 jul 2026
  • Túnel nativo v2 — solo Node.js + WebSocket; sin binario frpc (evita falsos positivos de antivirus).
  • CLI npm usa modo nativo por defecto; --frp / --legacy para el modo anterior.
  • API v2.0.0 con gateway HTTP en :18080 y WebSocket en /tunnel/ws.
  • Instalador curl actualizado: instala vía npm (requiere Node 18+).

1.0.9

30 jul 2026
  • Cambiar contraseña desde el dashboard.
  • Admin: suspender usuario y cerrar todos sus túneles.
  • Purga automática de túneles obsoletos (install-cron.py).

1.0.8

30 jul 2026
  • Dashboard: botón Cerrar en túneles activos.
  • deploy.py incluye subida de admin-web/.
  • Guía de monitorización en la documentación del repo.

1.0.7

30 jul 2026

Añadido

  • Recuperación de contraseña por email (olvidé mi contraseña).
  • Panel admin en dtunnel-admin.desarrollado.com.
  • Dashboard: túneles activos y liberar subdominios reservados.

Cambiado

  • /admin.html redirige al subdominio admin.

1.0.6

30 jul 2026

Añadido

  • Heartbeat de túneles (POST /api/tunnels/:subdomain/heartbeat) — limpieza automática sin ping en 10 min.
  • Rate limiting en registro, login y creación de túneles.
  • Límite anónimo por IP (cada visitante su propio slot).
  • Páginas legales: Términos, Privacidad, Uso aceptable.
  • Página de estado y GET /api/status.

Actualizar: npm install -g @desarrollado/dtunnel@latest

1.0.5

30 jul 2026

Añadido

  • DELETE /api/tunnels/anonymous — libera túneles anónimos huérfanos en el servidor.

Corregido

  • La API reclama el slot anónimo al crear un túnel sin sesión.
  • CLI npm/bash reintenta tras liberar el slot si no hay tunnel.json local.
  • Extracción de frpc en Windows.

Web

  • Documentación y dashboard: aclaración de subdominios, reservas y túneles activos.

Actualizar: npm install -g @desarrollado/dtunnel@latest

1.0.4

30 jul 2026

Añadido

  • DELETE /api/tunnels/:subdomain — libera el túnel en el servidor al hacer dtunnel down.
  • Limpieza automática de túneles huérfanos en la API (> 2 h).

Corregido

  • Error «Límite de túneles alcanzado» por registros fantasma tras cerrar el CLI.
  • dtunnel --port libera túneles locales muertos antes de crear uno nuevo.
