Comenzar en 2 minutos

  1. Instala dtunnel

    Linux, macOS o WSL — un solo comando (incluye frpc):

    curl -O https://install.desarrollado.com/dtunnel/install && sudo bash install

    Windows sin WSL: npm install -g @desarrollado/dtunnel (requiere Node 16+ y frpc aparte) · npm

  2. Levanta tu app y abre el túnel 
    python -m http.server 88080   # en otra terminal
dtunnel --port 88080
